# BattleCards 4.0.0

Clean rebuild of the BattleCards Spigot 1.12.2 plugin. The existing 288-card library is preserved.

## Main commands
- `/bc player` — enter BattleCards mode
- `/bc stop` — leave BattleCards mode
- `/bc cards` — inspect class cards and unlock state
- `/bc class <class>` — choose a class
- `/shop` — buy cards with Card Coins (CC)
- `/missions` — view missions
- `/match queue|leave|status` — official matchmaking
- `/challenge <player>` and `/accept` — direct matches
- `/bot easy|normal|hard [class]` — practice bot
- `/bot remove` — remove your practice bot
- `/ritual <player> <card>` — ritual
